# Неделя 4 — Движение по окружности и delta time
Треугольник движется по окружности, а сам треугольник пульсирует.

- **D** — переключает `dt`: с `dt` скорость не зависит от FPS, без него зависит
- **W / S** — увеличить / уменьшить скорость вращения
- **ESC** — выход
