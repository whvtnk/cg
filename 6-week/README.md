# Неделя 6 — Шар, прямоугольник и каркасный режим

Шар подпрыгивает по параболе под действием гравитации. Прямоугольник движется слева направо и появляется с другой стороны, когда уходит за край экрана.

- **TAB** — переключает каркасный режим (`glPolygonMode`)
- **ESC** — выход
