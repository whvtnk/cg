# 12-апта — Бірнеше текстура

Бір кубта екі текстураны (жәшік пен өрнек) араластыру: текстуралық бірліктер, `mix` коэффициентін uniform арқылы басқару, логотипті альфамен жапсыру және UV бойынша ауысу.

## Пернелер

| Перне | Әрекет |
|-------|--------|
| `↑` / `↓` | `blend` арттыру / азайту |
| `1` | `mix(a, b, blend)` |
| `2` | `a * b` |
| `3` | `a + b` |
| `4` | `clamp(a + b, 0, 1)` |
| `5` | логотип альфамен |
| `6` | `mix(a, b, vTexCoord.y)` |
| `7` | `smoothstep(0.3, 0.7, vTexCoord.y)` |
| `8` | үш текстура |
| `U` | `glActiveTexture`-сыз (1-тапсырма) |
| `I` | бірлік нөмірінің орнына ID (2-тапсырма) |
| `B` | автоматты `blend` |
| `F` | әр жаққа бөлек коэффициент |
| `L` | логотипті айналдыру |
| `R` | бастапқы күйге қайтару |
| тінтуір, дөңгелек, `W A S D` | камера |
| `Esc` | шығу |
