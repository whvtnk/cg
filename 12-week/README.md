# 12-апта — Бірнеше текстура

Бір кубта екі текстураны араластыру: текстуралық бірліктер және араластыру коэффициентін uniform арқылы басқару.

## Басқару

| Перне | Әрекет |
|-------|--------|
| тінтуір, `W A S D` | камера |
| `↑` / `↓` | `blend` көбейту / азайту |
| `1` `2` `3` `4` | `mix` / `a * b` / `a + b` / `clamp(a + b)` |
| `5` | логотипті альфамен жапсыру |
| `6` / `7` | `vTexCoord.y` / `smoothstep` бойынша ауысу |
| `8` | үш текстура |
| `U` | `glActiveTexture`-сыз |
| `I` | бірлік нөмірінің орнына ID |
| `B` / `F` / `L` | автоматты `blend` / әр жаққа бөлек / логотипті айналдыру |
| `R` / `Esc` | бастапқы күй / шығу |


## Тапсырмалар

**Базалық бөлім.** Екінші текстураны жүктеп, шейдерде `mix(texture1, texture2, blend)` арқылы араластыру; `blend`-ті жоғары/төмен пернелерімен `dt`-ге көбейтіп өзгерту.



**1. Бірліктерді әдейі шатастыру.** Екі `glActiveTexture` жолын алып тастап, `blend = 0` және `blend = 1` кезінде не көрінетінін бақылау: екі текстура да 0-бірлікке түседі, 1-бірлік бос қалады.



**2. Қатерлі қате.** `glUniform1i`-ге бірлік нөмірінің орнына текстура ID-ін (`tex2 = 2`) беріп, ID-лерді терминалға шығару: үшінші текстура қосылғанда қате кенеттен «пайда болады».



**3. Төрт араластыру тәсілі.** `mix`, `a * b`, `a + b`, `clamp(a + b)` нұсқаларын салыстыру: көбейту тек қараңғылатады, қосу ағартады.



**4. Логотипті альфамен жапсыру.** Төрт арналы `logo.png`-ді `mix(base, decal, decal.a)` арқылы жапсыру: `a = 0` — жәшік, `a = 1` — логотип, шеттерінде жұмсақ ауысу.



**5. Кеңістіктік ауысу.** Коэффициентті `vTexCoord.y`-тен алу, содан соң `smoothstep(0.3, 0.7, y)` арқылы ауысуды тіктеу.



**6. Қосымша тапсырмалар.** Үш текстура, `sin` арқылы автоматты `blend`, әр жаққа бөлек коэффициент және логотипті айналдыру.
